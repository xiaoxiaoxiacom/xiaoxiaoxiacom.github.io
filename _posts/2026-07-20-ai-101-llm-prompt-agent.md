# AI入门第一课：大模型、Prompt、智能体到底是个啥？

![AI 总览](https://loremflickr.com/cache/resized/65535_54587965789_bf6b3632e8_o_800_450_nofilter.jpg)

2026 年了，AI 已经不是科幻电影里的概念，而是打工人手边的真实生产力工具。但很多人一打开 AI，就被满屏的术语劝退：**大模型、Prompt、智能体、Agent、LLM……** 这些词到底是什么意思？

今天这一课，我用大白话把三个最核心的概念讲清楚。读完你会发现：它们一点都不玄，就是"大脑、语言、手脚"的关系。

---

## 一、大模型（LLM）：AI 的"大脑"

![神经网络示意](https://loremflickr.com/cache/resized/65535_52781713009_ba9f911cd3_c_800_450_nofilter.jpg)

**一句话定义**：大语言模型（Large Language Model，简称 LLM）是在海量文本上训练出来、能理解和生成人类语言的 AI 模型。

**它到底怎么工作？**
本质就一件事：**预测下一个词**。你给它一段上文，它根据学过的海量知识，猜出"下一个最合理的词"是什么，一个词一个词连成句子。你之所以觉得它"像人"，是因为它读过几乎整个互联网。

**一个生活类比**：
大模型像一个**读完了全网书、记性超好、但没什么主见的超级助理**——你不问，它不答；你问得越清楚，它答得越好。它不会"凭空创造真理"，而是把你已有的知识重新组织、表达出来。

**它能做 vs 它做不好**：

| 大模型擅长 | 大模型不擅长 |
|---|---|
| 写文章、改文案、翻译 | 获取实时信息（看不到今天的新闻） |
| 写代码、debug | 精确数学计算（容易算错大数） |
| 总结长文、提取要点 | 替你做关键决策、担责任 |
| 角色扮演、头脑风暴 | 辨别你给它的信息真假 |

**主流大模型速览**（新手不用全记，先选一个用熟）：

| 名称 | 特点 | 适合场景 |
|---|---|---|
| GPT（OpenAI） | 综合能力强，生态成熟 | 通用创作、编程 |
| Claude（Anthropic） | 长文理解、写作细腻 | 阅读、写作、分析 |
| 文心一言 / 通义千问 / 豆包 | 中文友好、国内可用 | 日常办公、中文创作 |
| ima | 内置知识库与智能体 | 个人知识管理 + 中国语境 |

> 💡 新手建议：**别纠结哪个最强**，先挑一个天天用，比反复横跳强十倍。

## 二、Prompt（提示词）：你和 AI 的"沟通语言"

![人机对话](https://loremflickr.com/cache/resized/65535_53462729575_3556fe99b9_h_800_450_nofilter.jpg)

**一句话定义**：Prompt 就是你发给 AI 的那句话 / 那段指令。

**为什么它重要？**
同一个 AI，Prompt 写得好坏，结果能差出十条街。AI 很"听话"，但也"死板"——你含糊，它就瞎猜；你精确，它就精准。

**万能 Prompt 公式**（记住这 5 个要素，覆盖 90% 场景）：

> **角色 + 任务 + 背景 + 要求 + 格式**

- **角色**：「你是一位有 10 年经验的新媒体运营」
- **任务**：「帮我写一份小红书选题方案」
- **背景**：「面向刚生完孩子的职场妈妈」
- **要求**：「突出时间紧、精力少的痛点，语气亲切」
- **格式**：「用表格输出 10 个选题，每题一句话说明」

**反面案例 vs 正面案例**：

| | 写法 | 结果 |
|---|---|---|
| ❌ 差 | "帮我写个方案" | AI 不知道给谁写、写什么、什么格式，只能瞎编 |
| ✅ 好 | "你是有10年经验的新媒体运营，给'职场妈妈'写10个小红书选题，每题一句话说痛点，表格输出" | AI 精准输出可用方案 |

**两个进阶小技巧**：
1. **给示例**：你希望它照着某种风格写，就先贴一段范例；
2. **让它反问**：加一句"如有不清楚的先问我，确认后再写"，能避免跑偏。

## 三、智能体（Agent）：会自己干活的"AI 员工"

![智能体 / 机器人](https://loremflickr.com/cache/resized/1915_45207821922_622d8d816a_c_800_450_nofilter.jpg)

**一句话定义**：智能体（Agent）是能**自己规划步骤、调用工具、连续完成任务**，而不只是"一问一答"的 AI。

**它和普通对话 AI 的区别**：

| | 普通对话 AI | 智能体 Agent |
|---|---|---|
| 模式 | 你问一句，它答一句（被动） | 你给目标，它自己拆解执行（主动） |
| 能力 | 只会"说话" | 会读文件、联网、写代码、调 API |
| 例子 | "帮我写周报" → 它给文字 | "把销售表做成月度分析" → 它自动读表、清洗、画图、出报告 |

**一个具体例子**：
你对智能体说"把这份销售表做成月度经营分析"。它会自己：
1. 读取并理解 Excel；
2. 清洗异常数据；
3. 按地区 / 月份汇总；
4. 生成可视化图表；
5. 写出结论和建议；
6. 输出一份完整报告。

你从头到尾只说了一句话。

**在哪能用到？**
ima 智能体、Coze、Dify 等平台都能搭建或直接使用现成智能体，不用写代码。

## 四、一张图理清三者关系

> **大模型 = 大脑**（提供能力底座）
> **Prompt = 语言**（你如何指挥它）
> **智能体 = 手脚**（把能力变成实际产出）

打个比方：大模型是发动机，Prompt 是方向盘和油门（你告诉它去哪、多快），智能体是整车——把动力真正开到目的地。

三者关系串起来就是：**大模型提供能力 → 你用 Prompt 激活能力 → 智能体把能力自动变成结果。**

## 五、普通人今天就能开始的 3 件事

1. **注册一个大模型**（如 ima），今天就用它回答你工作的一个小问题；
2. **套用万能公式**重写你的下一个 AI 请求（角色+任务+背景+要求+格式）；
3. **试用一个现成智能体**（比如 ima 里的 Excel 分析助手），体验"说一句话就出报告"。

记住：**懂这三个词，你就超过了 80% 只会喊"AI 好厉害"的人。** 下一步，就是把它们用起来。
